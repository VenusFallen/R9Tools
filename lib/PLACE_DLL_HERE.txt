Copy ALL DLLs from the LHM zip into this directory to enable the Stats overlay.

Download LHM.zip (not LHM.net10.zip) from:
  https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases

Copy every .dll file from the zip into this folder — LibreHardwareMonitorLib.dll
is the main assembly, and the rest (currently ~30+ files: Aga.Controls,
HidSharp, Newtonsoft.Json, the System.* polyfills, etc.) are its runtime
dependencies. The exact set of dependency DLLs changes between LHM releases,
so don't hand-pick a subset — stats_poller.py loads everything it finds in
this directory via Assembly.LoadFrom.

Also required (pip install):
  pip install pythonnet>=3.0.0

Run R9Tools as Administrator — LHM requires elevated privileges to read hardware sensors.
